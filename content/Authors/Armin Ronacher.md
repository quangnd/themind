# Armin Ronacher

Austrian software engineer, prolific open-source author, and co-founder of Sentry. Best known as the creator of the Flask web framework, Jinja2 templating engine, Werkzeug WSGI toolkit, and Click (CLI library). Blogs at [lucumr.pocoo.org](https://lucumr.pocoo.org). Active on GitHub and X as `mitsuhiko`.

His writing spans Python internals, developer tooling, software architecture, and — increasingly — the practical use of AI agents in software development. He has a reputation for thoughtful, opinionated technical posts that cut through hype.

## Notable Work

- **Flask** — lightweight Python web framework; one of the most widely used web frameworks in the Python ecosystem
- **Jinja2** — Python templating engine
- **Werkzeug** — comprehensive WSGI web application library
- **Click** — composable command line interface toolkit for Python
- **Sentry** (co-founder) — error tracking and performance monitoring platform
- **agent-stuff** — public repository of Pi skills and extensions he's built with his agent

## Earendil

Co-founder of [[Earendil]], a Vienna-based AI company building agent-powered products. Products include Elwing (email agent) and Pi. Mario Zechner joined as shareholder and pi lead in April 2026.

## On AI Agents

Became a strong advocate for minimal, self-extending agents after working with [[Pi (Coding Agent)]] and observing [[OpenClaw]]'s growth. His view: LLMs are excellent at writing and running code, so the right architecture leans hard into this rather than building elaborate scaffolding around it. Co-founder of the [[Vienna School of Agentic Coding]] (the name spectators gave to his collaboration with Mario Zechner and Peter Steinberger).

Key positions:
- Prefers agents with tiny cores (4 tools, minimal system prompt) over feature-rich frameworks
- Builds custom skills via the agent itself rather than downloading community extensions
- Replaced browser automation MCP/CLIs with a single CDP-based skill the agent maintains
- Does not use plan mode; prefers natural back-and-forth with the agent asking questions in prose
