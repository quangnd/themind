It's about **What we will do** and **What we won't do**.

![[Attachments/Scope_of_project.png]]

> Scope = The plan that keeps your project focused

Some times it's about "**How big it will be**" (only one tree, not a forest) and "**When it should be done**" (before summer vacation ends)

(Why?) If we don't define a scope, we keep adding ideas (_let's add a swimming pool_), which also known as [[Scope creep]], and the project never finishes.

> [!tip]
> Scope keep team focused so project gets built on time.

With your scope, you need to know how much money you can spend for this project. In other ways, you should have a [[Budget|Budget plan]]. After that, you can start [[Schedule|Schedule for project]].

When [[Scope of the project]] is fixed, unexpected changes can be managed by altering [[Budget]] or [[Schedule]]
